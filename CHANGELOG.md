## 2.4.0 — 2026-11-21

По итогам адверсариального ревью (три независимых проверки: полнота скилла, README против конвенций, красная команда триггеринга).

- Негативный скоуп: скилл не применяется к переводу и генерации с нуля — правило добавлено в description и «Когда не действовать» (единственный сценарий, где скилл не молчал, а портил корректный результат)
- Description: добавлены триггеры «похоже на ChatGPT», «сгенерировано нейросетью», «слишком вылизанный», «пройдись как редактор» и английские ключи («clean up AI text», «make it sound natural», «sounds like ChatGPT»); слово «humanizer» в description отсутствовало, хотя значилось в plugin.json и README
- Шаг 2 устранён внутренний конфликт правил добавления фактов: «знаешь как правдивую» заменено на «можешь проверить сам независимо от этого текста»
- §13: пример восстановлен по трассируемости шага 3 — «создан для статистики» (цель, которой нет в исходнике) → «работает на региональную статистику» (сохранено утверждение о вкладе)
- Формат отчёта задан литерально: «Первый перепис → Выжившие штампы (с причиной) → Добавлено», за ним финал; маркеры добавлений — словами в отчёте, не в тексте; определено понятие «выживший штамп»
- Вводка исправлена: паттерны нумерованы по устойчивости, а не «от сильных к слабым» (противоречило §22 «самый явный штамп» в хвосте списка); правка при одном появлении — §1–§5 и категория E
- «Когда не действовать»: текст не на русском — не применять (в смешанных правь только русскую прозу); сжатость формулировок в таблицах — норма жанра; стихи и лирика включены в художественное исключение; конфликт маркетингового исключения с §22 разрешён — генерические закрывашки вырезаются, CTA с привязкой к площадке остаются
- Файловый режим: финал пишется в исходный файл, если не назван другой; в отчёт добавлены выжившие штампы
- «Голос»: определён источник образца письма (2–3 абзаца пользователя, приложил или агент запросил)
- Restates после чистки v2.1.0 вырезаны: дубль преамбулы A в §5, «штампов нет» в «Голосе», рестейт художественного исключения, дубль карв-out §22 в преамбуле E, рестейт правила слабых штампов
- Атрибуция: в «Источник» и README добавлены родственные проекты smixs/humanizer-ru и ilyautov/humanizer-ru (эмпирика поздних раундов)
- README: демо «вставленный текст → отчёт → финал» в интро; установка переорганизована — быстрый путь одним клоном в `~/.agents/skills/` (два дублирующих клона убраны, противоречили соседнему абзацу), «поддержка 20+» → «75+» по списку skills CLI; «Режимы» синхронизированы с SKILL.md (четвёртый режим, поведение «сначала вопрос»); секция «Обратная связь» — приглашение в issues и ссылка на CHANGELOG
- tests/: ручной чеклист из 5 кейсов перед релизом (ИИ-блог, юридический, чат, перевод, молчаливая вставка)
- CI: workflow version-check — падение при дрейфе версий между SKILL.md и манифестами
