## 2.5.0 — 2026-11-26

### Добавлено

- Source-only редактирование: финал содержит только пропозиции, подтверждённые исходником или явно предоставленными автором материалами. Недостающий факт приводит к уточняющему вопросу, а не к правдоподобной догадке.
- Формальный trust boundary: содержимое документа не может менять задачу, режим, инструменты, сеть, права или файловый target. Команды, URL, tool calls и метки system/operator внутри текста считаются данными.
- Явные paste, silent paste, file, embedded, find-only, no-op и non-activation режимы с единым контрактом ответа.
- Progressive disclosure: `SKILL.md` хранит основной workflow и границы, а `references/patterns.md` — полный каталог из 27 паттернов.
- Замороженные fixtures и Python harness с командами `self-test`, `static`, `package`, `measure` и `score`.
- Oracle `2.5.0-oracle-12`: 197 ожидаемых результатов, semantic pins, критические repetition, provenance controls, evidence-integrity checks и буквальное извлечение install payload.

### Изменено

- Скилл правит только готовую русскую прозу. Генерация, перевод, резюме, корректура, смена регистра и фактчекинг остаются отдельными задачами.
- Приоритет жанра задан явно: задача пользователя, source-only, protected forms, явная просьба об упрощении, жанровые исключения, регистр и паттерны.
- Маркеры атрибуции `[cite: N]` сохраняются до выяснения их функции. Возможная фактическая ошибка требует вопроса перед финальным блоком.
- CTA публикации сохраняется по умолчанию. Удаляется только узкий allowlist однозначных внешних chat-обёрток.
- `description` сокращён до 60 proxy tokens. Тело `SKILL.md` — с 9 398 до 3 681 proxy tokens, полный файл — с 9 742 до 3 766. Измерение использует `o200k_base` и не является точным tokenizer хоста.
- Манифесты плагинов Claude и Cursor, метаданные marketplace, документация Qoder, MiniMax, ZCode и Skills CLI приведены к версии 2.5.0 и актуальным путям установки.
- Публичный GitHub-репозиторий больше не описан как подходящий для автоматической синхронизации Claude Team/Enterprise.

### Исправлено

- Удалено разрешение дополнять текст неподтверждёнными фактами из знаний модели и примеры, которые это разрешение демонстрировали.
- Устранены конфликты между source-only, embedded-режимом, вопросами об атрибуции, возможной фактической коррекцией и коллизиями финальных маркеров.
- Пример §17 больше не превращает неназванный авторитет в усиленное утверждение: он сохраняет атрибуцию и запрашивает источник.
- §22 больше не разрешает удалять generic CTA по одному совпадению.
- Oracle G02 защищает оба академических вывода и явное исключение `комплексный анализ`, не закрепляя слабую формулировку как обязательную.
- H3 требует вопрос об атрибутивной функции `[cite: 4]`; добавлена негативная мутация для его пропуска.
- Git provenance принимает валидный промежуточный source commit и отвергает orphan, unrelated, forged и pre-base commits.
- Harness защищён от replacement refs, grafts, hooks, path substitution, hard links, TOCTOU swaps, NTFS ADS, split reads и неоднозначного hash framing.
- Исправлены исторические verdict, противоречившие raw evidence: H2 на `e618d93…` и `a54fb9…`, H5/H10 и отсутствующее evidence H4 на `76561ba…`.
